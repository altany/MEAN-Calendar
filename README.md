# MEAN-Calendar
A simple restful Calendar app with AngularJS, Node.js, Express and MongoDB

This is an extension of the [To-do List App](https://github.com/altany/MEAN-ToDoApp) I created with the MEAN stack

Built in 2015 and archived. The Heroku demo and its mLab database no longer exist, so the code is kept for reference. The database URL is read from `MONGODB_URI`.

*To install and run this app, [this blog](http://cwbuecheler.com/web/tutorials/2013/node-express-mongo/) is very useful*
